# Bot de Telegram FQS

Bot para generar los formatos FQS-OPE-F001 y FQS-OPE-F008 desde Telegram.

## Railway

Variable requerida:

- `TELEGRAM_BOT_TOKEN`: token privado del bot de Telegram.

Comando de inicio:

```bash
python -m telegram_bot
```

El FQS-OPE-F001 admite texto y evidencia fotográfica. El FQS-OPE-F008 utiliza texto.
